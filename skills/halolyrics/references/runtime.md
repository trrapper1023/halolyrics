# 运行与故障定位

- 登录项 `local.halo.netease-lyrics` 在用户图形会话中运行。每次安装复用同一个服务名。只用 `manage.sh status` / `doctor` 查看状态，避免启动第二个进程。
- 原生适配器通过系统媒体状态获取 bundle ID、歌曲、歌手、时长、播放标志和当前秒数。只匹配 `com.netease.163music`；通过网易云搜索以曲名、歌手和时长匹配录音，再按歌曲 ID 请求 LRC。网络超时后轮询重试。
- USB 设备厂商 ID `2d99`，控制 usage page `ff14`。V2 帧为 64 字节，带长度、校验和及填充。文字用 `0xe8`，场景/对齐用 `0xef`。查看协议源文件和上游记录确认字段，勿探测其他 USB 接口。
- 按播放时间选择 LRC 行。帧限制 48 UTF-8 字节和估算的 32 列；用字素簇切分。只有超长行才推进窗口，换行前停留在句尾。设备用原生居中布局。
- 时钟和歌词由后台持有同一个控制接口；TempoHub 进程运行时后台释放接口并停发。退出要用 `⌘Q`。如有独占错误，排查残留 TempoHub 或手工运行的旧同步进程。不要盲目杀进程。
- 无设备先检查 USB 数据线和声卡输入模式。无媒体状态先看 macOS 是否识别官方 App 的播放。匹配失败先核对是否为不同录音、现场版或缺失 LRC。
